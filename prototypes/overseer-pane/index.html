7 · Decision facts for #571

  • A pane overseer needs no new chat-page code for normal turns. The pane path serves it as it serves an agent.
  • The take back is the proved #542 flow: Escape interrupts at once, double Escape opens rewind, blind counting picks the landing, Ctrl-C clears the prefill. Curia enforces the floor and writes the receipt. The ADR-0023 journal append retires if panes win.
  • One build change for the chat: the tailer follows the active branch by parentUuid, for both chat kinds, and the receipt carries the landing point.
  • Notes batch through a bracketed paste — tmux.mjs gains a paste write beside sendText.
  • The pane seed extends the agent seed with customApiKeyResponses for the env credential (a first-spawn approval dialog otherwise).
  • Costs, hosting, restart rehydration, and MCP identity are the #569 research facts, unchanged.
