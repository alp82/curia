10the guide

Set it up

What you need: One Linux box with Docker, Tailscale, a Discord server and your coding agent subscription

1Tailscale

Install Tailscale on the box and on your phone. Turn on HTTPS certificates for your tailnet, then run tailscale set --operator=$USER.

2GitHub

Log in with gh auth login. Create the GitHub App curia uses to reach your repos, and install it on each owner you watch.

3The Discord bot

Create a bot, turn on the message content intent, and invite it to your server. It makes the #curia channel itself.

4Two files

Put the bot token in daemon/.env.daemon. Put your repos and a workspace root in config/curia.yaml.

5Run it

docker compose -f deploy/compose.yaml up -d --build

Send a message in #curia, and a thread answers you.

All steps are described in the set up guide
